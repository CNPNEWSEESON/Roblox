## 1️⃣ ตั้งค่าโปรเจกต์
- [ ] สร้างแผนที่หลัก + บ้านผู้เล่น (แต่ละคนมี Plot ของตัวเอง)

## 2️⃣ ถ้ำส่วนตัว

- [ ] ป้องกันโกง: ตรวจ Cooldown ฝั่ง Server

## 4️⃣ ระบบสุ่มตัวละคร (Server)
- [ ] ตารางโอกาสแบบ **chain** ทีละด่าน (1/100 ถึง 1/100Td)
- [ ] 12 Tier: Common → Uncommon → Rare → Epic → Legendary → Mythic → Divine → Celestial → Cosmic → Eternal → Omega → Secret
- [ ] ผูกด่านที่สุ่มได้กับความลึก (ตื้นสุ่มได้ไม่สูง)
- [ ] Luck เป็นตัวคูณ + ใส่เพดาน/สูตรลดทอน (`luck^0.5` ด่านลึก)
- [ ] ประกาศทั้งเซิร์ฟเวอร์เมื่อเจอ Mythic ขึ้นไป

## 5️⃣ ระบบตัวละคร
- [ ] ข้อมูลตัวละคร: ชื่อ, Tier, เงิน/วินาที, โมเดล

## 1️⃣4️⃣ ระบบ Rebirth แบบเต็ม (หลายชั้น)

- [ ] แต่ละชั้นมีไอคอน/สีชื่อข้างหัวผู้เล่นต่างกัน (อวดได้)

### ต้นไม้สกิล Rebirth (Rebirth Tree)

### 🍀 Luck: ยิ่งเยอะยิ่งขุดง่าย แต่ตัวดีหายากขึ้นเรื่อยๆ
แนวคิด: Luck ช่วยเยอะตอนต้น แต่ยิ่งไล่ล่าตัวแรร์ลึกๆ ยิ่งได้ผลน้อยลง เพื่อไม่ให้เกมพังและมีเป้าหมายให้ไล่ตลอด

- [ ] **Luck ช่วย 2 ทาง:**
  1. **ขุดง่าย:** Luck สูง ลดความแข็งของบล็อก ขุดผ่านเร็ว
  2. **เจอแรร์:** เพิ่มโอกาสผ่านด่านแต่ละด่าน
- [ ] **Diminishing Returns ต่อด่าน:** ด่านลึกๆ ได้ผลจาก Luck น้อยกว่าด่านต้น
  - สูตรตัวอย่าง: `effectiveLuck = luck ^ (1 / (1 + stageIndex × 0.15))`
- [ ] **Soft Cap:** Luck เกินค่าหนึ่งแล้วโตช้าลง (เช่น หลัง 1,000 ใช้ log)
- [ ] **Rarity Resistance (ความต้านทาน):** ยิ่ง Tier สูง ตัวละครยิ่ง "หนีโชค" ต้องใช้ Luck ระดับขั้นต่ำถึงจะเริ่มได้ผล
- [ ] **ความแข็งบล็อกเพิ่มตามความลึก:** ต้องอัพ Dig Power ให้ทัน ไม่งั้นขุดไม่เข้า
- [ ] **Pity ขั้นสูง:** นับจำนวนขุดที่ไม่เจอ Tier นั้นๆ เพิ่มโอกาสขึ้นเรื่อยๆ และรีเซ็ตเมื่อเจอ
- [ ] แสดงใน UI: Luck รวมทั้งหมด, Luck ที่ได้ผลจริงของแต่ละ Tier, โอกาสปัจจุบัน

### Stat ผสมพิเศษ (Synergy)
- [ ] Luck + Radius = ขุดกว้างได้สุ่มหลายครั้งต่อการขุดหนึ่งครั้ง
- [ ] Crit + Dig Power = ขุดทะลุหลายชั้นพร้อมกัน
- [ ] Find Chance + Magnet = สายออโต้
- [ ] Build presets: เซฟสถานะแบบ Loadout 3 ชุด สลับได้

## 1️⃣7️⃣ ระบบการขุดแบบพิเศษ

- [ ] **Dig Radius:** ขุดเป็นวงกว้าง (วงกลม / กากบาท / ทรงกลม 3D)
- [ ] **Vein Miner:** ขุดเจอเส้นแร่แล้วขุดต่อเนื่องเป็นลูกโซ่
- [ ] **ระเบิด (TNT / Dynamite):** ระเบิดเป็นหลุมใหญ่ ได้ตัวสุ่มหลายตัวพร้อมกัน
- [ ] **ขุดทะลุชั้น (Drill Down):** เจาะลงแนวดิ่งหลายร้อยเมตรครั้งเดียว
- [ ] **ขุดคริติคอล:** ขุดลึกเป็นหลายเท่า + เอฟเฟกต์
- [ ] **Combo:** ขุดต่อเนื่องไม่หยุด ตัวคูณ Combo เพิ่มขึ้น (หยุดแล้วรีเซ็ต)
- [ ] **ชั้นหินแข็ง/บอสบล็อก:** ต้องใช้ Dig Power ถึงขั้นถึงขุดได้ (กันข้ามขั้น)
- [ ] **ห้องลับ (Secret Chamber):** สุ่มเจอห้องที่มีตัวละครหลายตัว/หีบสมบัติ
- [ ] **หีบสมบัติ:** ได้น้ำยา, Gems, วัตถุดิบ, ตัวละคร
- [ ] **Biome ในถ้ำ:** ถ้ำน้ำแข็ง, ถ้ำลาวา, ถ้ำคริสตัล, ถ้ำเห็ด (แต่ละที่ตัวละครเฉพาะ)

## 1️⃣9️⃣ ระบบตัวละครขั้นสูง

- [ ] **Trait เพิ่มเติม:** Shiny (x2), Rainbow (x5), Golden (x10), Void (x25), Cosmic (x100), Glitch (x500)

- [ ] **Evolution:** ตัวละครวิวัฒน์เมื่อ Level ถึงขั้น (รูปร่างเปลี่ยน)
- [ ] **ล็อกตัวละคร (Favorite):** กันกดรวม/ขายพลาด
- [ ] **ขายตัวซ้ำ:** แลกเงิน/Gems
- [ ] **Auto-merge** ตัวละครซ้ำ (Gamepass)
- [ ] **Index Rewards:** สะสมครบหมวดได้โบนัสถาวร (Luck/เงิน)
- [ ] **Secret ตัวพิเศษ:** ได้จากเงื่อนไขลับ เช่น ขุดครบความลึกในเวลาจำกัด, อีเวนต์

## 2️⃣0️⃣ อีเวนต์และสภาพแวดล้อม

- [ ] **Meteor Shower:** ตัวละครสุ่มตกลงมาในถ้ำ
- [ ] **Gold Rush:** เงินจากการขุด x5 ชั่วคราว
- [ ] **Lucky Hour:** Luck x2 ทั้งเซิร์ฟเวอร์
- [ ] **Lava Flood / Earthquake:** ขุดยากขึ้นแต่ตัวดีขึ้น (High risk, high reward)
- [ ] **Boss Cave:** ต่อสู้/ผ่านด่านบอสแลกตัวละครเฉพาะ
- [ ] **Server Luck:** ผู้เล่นทุกคนร่วมกันบริจาคเงินเพื่อเปิดบัฟให้ทั้งเซิร์ฟเวอร์
- [ ] **ประกาศสุ่ม Secret ทั้งเซิร์ฟเวอร์** (ข้อความ + เสียง + ชื่อผู้เจอ)
- [ ] **อีเวนต์ตามเทศกาล:** ตัวละครและน้ำยาจำกัดเวลา
- [ ] **สภาพอากาศ/เวลา:** กลางคืนเจอตัวพิเศษบางชนิด

## 2️⃣1️⃣ ระบบให้คนเล่นต่อ (เพิ่มเติม)

## 2️⃣2️⃣ สูตรและค่าที่ควรทำเป็น Config (ปรับบาลานซ์ง่าย)

```lua
-- ตัวอย่าง Config กลาง ปรับค่าได้โดยไม่แก้โค้ด
local Config = {
	LuckDiminish = 0.15,         -- ยิ่งด่านลึก Luck ได้ผลน้อยลง
	LuckSoftCap = 1000,          -- เกินนี้ใช้ log
	PotionLuckCap = 50,          -- เพดาน Luck จากน้ำยา
	PotionSlots = 3,             -- ช่องน้ำยาเริ่มต้น
	PityStep = 0.02,             -- โอกาสเพิ่มต่อการขุดที่ไม่เจอ
	RebirthMultBase = 0.5,       -- ตัวคูณถาวรต่อ Rebirth
	RebirthCostGrowth = 2.5,     -- ราคา Rebirth คูณทุกครั้ง
	BlockHardnessGrowth = 1.12,  -- ความแข็งต่อความลึก
	OfflineEarnRate = 0.1,       -- เงินออฟไลน์เริ่มต้น 10%
}
```

- [ ] ทำ Config เป็น ModuleScript เดียว
- [ ] ทำเครื่องมือจำลอง (Simulator) ทดสอบสมดุล Luck/Potion/Rebirth 1 ล้านรอบ
- [ ] ล็อกตัวเลขทุกอย่างฝั่ง Server
